About AppDock

AppDock runs local projects in desktop windows or through their original native interfaces. Project code stays on your computer.

Opening projects

Select a saved Codex project, browse a folder, or open a website. Supported project types are detected automatically; unusual setups may need advanced launch settings.

Runtime and data

Projects run in their existing folders by default. Private source copies are optional. Supported build outputs and run records are kept in AppDock storage. Setup can download Node or compiled-language SDKs and packages. Python projects use a local interpreter with isolated dependencies. Existing project environment files can be used during normal launches; saved settings are encrypted on this computer.

Distribution status

AppDock 0.6.0 is a developer preview. Windows x64 is the tested host. Release candidates are unsigned. macOS and Linux have build workflows but are not yet verified releases.

Independent software by GoldRock AI. AppDock is not an OpenAI product or an official OpenAI integration.
