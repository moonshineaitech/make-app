A few useful details.

Before your
first double-click.

Will it work with my project?

Make App recognizes common JavaScript, TypeScript, Python, Rust, Go, Java, .NET, C/C++ and Ruby project workflows. Some projects still need platform SDKs, native libraries, hardware, credentials or running services. Libraries need an executable entry point. Read the compatibility details.

Does it copy my project?

Desktop launchers use your existing project folder, so keep it in place. They are not source-inclusive portable transfers. Static web exports copy the public build assets into a separate folder you can host.

Do I need Codex?

No. Use the desktop converter on its own, connect another coding tool, or call the local command-line interface. The Codex plugin is one way to use Make App.

Can I use the apps on my phone?

Export an existing static web build, host it over HTTPS, then open it in your phone’s browser and use its install option when available. Backend services still need a compatible host. Native desktop programs do not become phone apps.

Is it really free?

Yes. Make App is MIT-licensed open-source software. There is no Make App subscription or API key. Your project’s external APIs, services or hosting may have their own costs.

What should I know about the preview?

Preview builds are unsigned and macOS builds are not publisher-notarized. Clean-machine, physical-mobile and manual accessibility acceptance remain open. Run code from people you trust: project code runs with your account’s permissions. The independent Codex integration is not an approved OpenAI Directory listing.
